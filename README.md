# La nit del llop - Poster generator

Servicio en Go que genera el cartel de los eventos de "La nit del llop" (Orfeó Catalònia) a partir de un webhook de Typeform, y lo sirve para su descarga.

## Despliegue

Alojado en [Render](https://render.com).

## Desarrollo local

```
make build
make run
```

## Docker

```
make run-docker
```
